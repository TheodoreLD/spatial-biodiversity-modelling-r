CORRECTIONS APPLIED TO spiny_trunk_species.xlsx
(source: Dryad archive Data/Name_spiny_species/Spiny_species.xlsx; original NOT modified)
====================================================================

1. GENUS TYPO
   "Bridela retusa" -> "Bridelia retusa"
   Reason: "Bridela" is a misspelling of the genus Bridelia (Phyllanthaceae).
   Effect: unique genera 23 -> 22, matching the manuscript ("22 genera").

2. MISSING CONTINENT
   "Hura crepitans" Native: <blank> -> "Americas"
   Reason: Hura crepitans is Neotropical. The blank caused the data's Americas
   tally to read 44 instead of the correct 45 (Table 1).

3. CATEGORY STANDARDIZATION (Native column -> Table 1 vocabulary)
   "America"      -> "Americas"   (all rows)
   "Africa/asia"  -> "Africa/Asia" (Toddalia asiatica; capitalization)
   "Middle East"  -> "Asia"        (Gleditsia caspica; Caucasus/S. Caspian = West Asia)
                                    *** PLEASE CONFIRM this assignment. ***

4. RANGE-AVAILABILITY FLAGS (Range column) — corrected against the actual range files
   "Dalbergia horrida"       Range: Yes -> No   (no .gpkg range file exists for it)
   "Zanthoxylum ovalifolium" Range: No  -> Yes  (a .gpkg range file exists and was used)
   Reason: the two Range flags disagreed with the range-map source
   (Data/Range_spiny_species/TreeSpecies.zip: 74 species, 2 .gpkg each).
   The richness maps are built by rasterizing the actual .gpkg files
   (R/01_biogeography.R), so the analysis ALREADY used
   Zanthoxylum ovalifolium and excluded Dalbergia horrida. Results are therefore
   unchanged (74 mapped species = 46 prickly + 28 thorny); this fix only makes the
   Range column honestly record which 74 species entered the maps. Before the fix the
   Range=Yes set implied 45 prickly + 29 thorny, which did not match the analysis.
